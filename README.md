# PDF-читалка для Firefox

Расширение для чтения PDF с экрана: перемотка **экранами, а не страницами**,
автопрокрутка с настраиваемой скоростью, озвучка текста с подсветкой
читаемого места, обрезка полей и ночные режимы.

Внутри — движок [pdf.js](https://mozilla.github.io/pdf.js/) (тот же, что во
встроенном просмотре Firefox) и собственный интерфейс поверх него.

## Что умеет

**Прокрутка**
- Шаг ровно на высоту экрана минус нахлёст, чтобы последняя строка не терялась
  на стыке (нахлёст настраивается, по умолчанию 8%).
- Плавная автопрокрутка с постоянной скоростью (1–400 px/с, кнопки «−» и «+»
  меняют её по шагу, мелкому на малых скоростях) — для сплошного текста.
- Автопрокрутка шагами: сдвиг на долю экрана через заданную паузу — когда
  удобнее читать «экран за экраном».
- Ручная прокрутка останавливает автоматическую, чтобы не бороться с курсором.
- **Закрепление вида** (замок рядом с масштабом или клавиша L): масштаб,
  например 200%, и положение по горизонтали фиксируются, дальше страница
  двигается только вниз и вверх. Закрепление запоминается для документа.
  Сдвинуть закреплённый вид вбок — Shift + ← / →.

**Озвучка**
- Кнопка «Озвучка» открывает панель. Пока панель открыта, **щелчок по тексту
  выбирает, откуда читать** — выбранное предложение подсвечивается, дальше ▶
  или S. Во время чтения щелчок сразу перескакивает в новое место.
  Можно и выделить кусок текста мышью и нажать S — чтение начнётся с выделения.
- Читает предложениями, подсвечивая текущее предложение и слово. Сокращения
  («проф.», «т. е.») и инициалы («А. С. Пушкин») фразу не рвут, разделители
  вроде «* * *» не зачитываются.
- Колонтитулы, номера страниц и сноски вслух не читаются: колонтитул
  узнаётся по повтору вверху и внизу страниц, сноска — по мелкому шрифту.
  Выключается в настройках.
- Таймер сна в панели озвучки: остановить чтение через 15–90 минут или в
  начале следующей главы; перед остановкой по времени голос плавно затихает.
- Страница сама едет за читаемым местом.
- Скорость, тон, громкость и голос; перемотка по предложениям.
- Голоса берутся из системы (Web Speech API). Можно подключить внешний движок
  по HTTP — например локальный Piper с нейросетевыми голосами,
  см. [docs/tts-http-provider.md](docs/tts-http-provider.md).

**Режим «только текст»** (кнопка «Текст» или клавиша T)
- Книга показывается сплошным текстом, перекомпонованным под ширину окна:
  свой шрифт, размер (Ctrl + / Ctrl −), межстрочный интервал, ширина колонки,
  выравнивание, переносы, цвета «бумага», «сепия» или «ночь». Крупно читать
  можно без горизонтальной прокрутки вообще.
- Колонтитулы и сноски убраны, заголовки и абзацы сохранены, номер страницы
  виден на полях.
- Работают автопрокрутка, перемотка экранами, озвучка с подсветкой, выбор
  места щелчком, закладки и память места. Поиск — обычный поиск Firefox
  (Ctrl+F).
- Картинки, таблицы и формулы в этом режиме не видны — для них есть обычный
  вид (снова T).

**Вид**
- Инверсия страницы с поворотом оттенка (картинки остаются похожими на себя),
  сепия, приглушение, ползунки яркости и контраста.
- Обрезка полей: поля определяются по содержимому страниц, масштаб «по ширине»
  считается уже от видимой части. Можно поправить руками.
- Тёмный и светлый интерфейс, режим без панелей (клавиша F).

**Навигация и память**
- Поиск по документу, миниатюры страниц.
- Оглавление с номерами страниц и подсветкой текущего раздела; повторяющиеся
  уровни («Глава → та же глава → * * *») схлопываются.
- Место чтения, масштаб и настройки обрезки запоминаются для каждого документа.
- Список недавних: файлы хранятся в браузере, открываются одним щелчком.
- Закладки: кнопка с флажком в тулбаре открывает список, «Добавить здесь»
  ставит закладку на текущее место, к ней можно дописать заметку. На полях
  страницы появляется красный флажок; щелчок по закладке в списке
  возвращает к этому месту. Клавиша B ставит закладку без открытия списка.

**Выделения и заметки**
- Выделите текст мышью — появится панелька с четырьмя цветами маркера и
  кнопкой заметки. Клавиша H выделяет последним выбранным цветом.
- Щелчок по маркеру — сменить цвет, дописать заметку или убрать выделение.
  Маркер с заметкой подчёркнут.
- Выделения видны и на страницах PDF, и в режиме «только текст»; выделение,
  сделанное в одном режиме, ложится на те же слова в другом.
- Вкладка «Заметки» в боковой панели: закладки и выделения по порядку
  страниц, переход по щелчку. Кнопка «Конспект .md» сохраняет всё одним
  файлом Markdown — цитаты разложены по главам из оглавления, с номерами
  страниц и заметками.

## Установка

Нужен Firefox 140 или новее.

### Постоянная установка с автообновлением

Firefox ставит насовсем только подписанные дополнения. Подписывает их
addons.mozilla.org (AMO) — бесплатно и без публикации в каталоге. В
репозитории это делает GitHub Actions: при каждой новой версии он подписывает
расширение и выкладывает его в **Releases**, а установленный Firefox сам
находит обновление. Настраивается один раз:

1. **Репозиторий публичный.** Settings → General → внизу Danger Zone →
   Change repository visibility → Public. Иначе Firefox не сможет без
   логина скачать обновление. В репозитории только код читалки: ваши PDF,
   закладки и ключи туда не попадают.
2. **Ключи AMO.** Войдите на https://addons.mozilla.org под аккаунтом Mozilla
   (тем же, что для синхронизации Firefox, или создайте новый), откройте
   https://addons.mozilla.org/developers/addon/api/key/, примите соглашение
   разработчика и нажмите **Generate new credentials**. Появятся два значения:
   *JWT issuer* и *JWT secret*.
3. **Секреты в репозитории.** Settings → Secrets and variables → Actions →
   New repository secret: `AMO_JWT_ISSUER` — значение JWT issuer,
   `AMO_JWT_SECRET` — значение JWT secret. Секреты видит только GitHub
   Actions, в коде и логах их нет.
4. **Первая подпись.** Actions → «Подпись и релиз» → Run workflow. Через
   несколько минут в Releases появится `pdf-reader-<версия>.xpi`.
5. **Установка.** Если стоит временная версия — удалите её в
   `about:debugging`. Скачайте `.xpi` из Releases и перетащите в окно
   Firefox → «Добавить».

Дальше Firefox проверяет обновления сам, примерно раз в сутки. Проверить
сразу: `about:addons` → шестерёнка → «Проверить наличие обновлений».

### Быстро, на одну сессию

1. Скачайте репозиторий (кнопка **Code → Download ZIP**) и распакуйте.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. **Загрузить временное дополнение…** → выберите файл `extension/manifest.json`.

Так расширение работает до перезапуска браузера — удобно, чтобы попробовать.
Закладки и список недавних временной версии при её удалении теряются.

Ещё путь без подписи — Firefox Developer Edition или ESR с выключенной
проверкой (`about:config` → `xpinstall.signatures.required` → `false`); в
обычном выпуске Firefox этот переключатель не действует.

## Как открывать документы

- **Ссылка на PDF в интернете** — открывается в читалке сама. Отключается в
  настройках («Открывать PDF-ссылки в этой читалке»).
- **Файл с компьютера** — кнопка «Открыть» или перетаскивание файла в окно.
  Расширения Firefox не имеют доступа к `file://`, поэтому локальный PDF
  нельзя открыть по ссылке — только выбрать или перетащить. Дальше он попадает
  в «Недавние» и открывается оттуда одним щелчком.
- **Правая кнопка** на ссылке или странице → «Открыть в PDF-читалке».
- **Значок расширения** на панели — открывает пустую читалку.
- **Скачать на компьютер** — кнопка «Скачать» рядом с «Открыть» или Ctrl+S.
  Сохраняется исходный PDF (а не страница читалки) — в «Загрузки» или туда,
  куда спросит Firefox, если он так настроен.

## Горячие клавиши

Клавиши работают в любой раскладке: читается физическая клавиша, а не буква.

| Клавиши | Действие |
| --- | --- |
| `Пробел`, `Page Down`, `→`, `J` | вниз на экран |
| `Shift+Пробел`, `Page Up`, `←`, `K` | вверх на экран |
| `↓` / `↑` | немного вниз / вверх |
| `Home` / `End` | в начало / конец документа |
| `G` | перейти к номеру страницы |
| `A` | автопрокрутка: пуск и стоп |
| `]` / `[` | быстрее / медленнее |
| `M` | режим автопрокрутки: плавно или шагами |
| `S` | читать вслух / пауза |
| `Shift+S` | остановить чтение |
| `.` / `,` | следующее / предыдущее предложение |
| `Shift+.` / `Shift+,` | читать быстрее / медленнее |
| щелчок по тексту при открытой панели озвучки | читать с этого места |
| `Alt` + щелчок | читать с этого места (даже при закрытой панели) |
| `T` | режим «только текст» |
| `I` | инверсия страницы |
| `C` | обрезка полей |
| `V` | панель вида |
| `F` | скрыть панели |
| `Ctrl` + `+` / `−` / `0`, `Ctrl` + колесо | масштаб |
| `L` | закрепить масштаб и положение |
| `Shift` + `←` / `→` | сдвинуть вид вбок |
| `F4` | боковая панель |
| `Ctrl+F`, `/` | поиск |
| `Ctrl+S` | скачать PDF на компьютер |
| `F3` / `Shift+F3` | следующее / предыдущее совпадение |
| `B` | закладка на текущем месте |
| `H` | выделить маркером то, что выделено мышью |
| `F1` | справка по клавишам |
| `Esc` | закрыть панели, остановить всё |

## Про озвучку

Качество голоса зависит от системы: в Windows берутся голоса SAPI, они же
сообщают границы слов — по ним подсвечивается читаемое слово. Если голос
границы не присылает, подсвечивается предложение целиком.

Если список голосов пуст, значит в системе не установлен ни один голос
синтеза речи. В Windows они добавляются в «Параметры → Время и язык → Речь».

Для голосов заметно лучше системных подключается внешний движок —
[инструкция и пример на Piper](docs/tts-http-provider.md).

## Разработка

```bash
npm install
npm run vendor     # перенести pdf.js из node_modules в extension/vendor
npm run sample     # сгенерировать тестовый PDF
npm run sample:ru  # русская книжная вёрстка для проверок (нужен LibreOffice)
npm run dev        # вьюер как обычная страница: http://localhost:8080/viewer.html
npm start          # запустить Firefox с расширением (web-ext run)
npm run lint       # проверка манифеста и кода расширения
npm test           # юнит-тесты чистой логики
npm run test:e2e   # сквозная проверка вьюера в Chromium
```

Структура:

```
extension/
  manifest.json        расширение (MV3)
  background.js        перехват PDF-ссылок, контекстное меню
  viewer.html          разметка читалки
  styles/viewer.css    оформление
  vendor/              pdf.js, переносится скриптом npm run vendor
  src/
    main.js            сборка приложения
    viewer-setup.js    ядро на компонентах pdf.js
    screen-nav.js      перемотка экранами
    autoscroll.js      автопрокрутка
    appearance.js      темы и цветовые режимы
    crop.js            обрезка полей
    text-index.js      текст документа и предложения
    tts/               озвучка: контроллер, подсветка, движки
    library.js         база: место чтения, закладки, файлы
    reading-state.js   память для каждого документа
    find-ui.js outline.js thumbnails.js bookmarks.js
scripts/               vendor, dev-сервер, генератор тестового PDF
tests/                 юнит-тесты и сквозная проверка
docs/                  протокол внешнего движка синтеза
```

Каталог `extension/vendor/` лежит в репозитории намеренно: так расширение
ставится из скачанного архива, без Node и сборки.

### Что проверено, а что нет

Вьюер целиком (чтение, прокрутка, автопрокрутка, обрезка, поиск, оглавление,
миниатюры, озвучка с подменённым синтезом, память места чтения) проверяется
сквозным тестом в Chromium: `npm run test:e2e`.

Перехват PDF-ссылок фоновой страницей проверен только линтером манифеста:
Firefox в среде разработки этого проекта недоступен. Если перехват не
сработает, расширение само переключится на запасной способ — подмену вкладки
по адресу вида `*.pdf`; в консоли фоновой страницы об этом будет запись
«перехват работает по адресу страницы».
